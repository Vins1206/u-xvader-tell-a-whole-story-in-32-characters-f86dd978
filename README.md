A make.fun bounty entry: one Wi-Fi network name of at most 32 characters
that tells a whole story and lands a joke.

## Entry

**`ILoveYou_SheSaidWrongPassword`** — 29 characters, one line.

The story: I finally confess my love, and she hears it as a Wi-Fi
password attempt and rejects it as the wrong password. Setup, two
characters, twist and punchline in a single network name a stranger
gets on the first read.

## How it works

`main.py` (Python standard library only) writes exactly that name —
no trailing newline, nothing else — to `/output/entry.txt`.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
